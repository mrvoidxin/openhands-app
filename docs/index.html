01 · Overview

What this actually is.

OpenHands Agent Canvas is the web interface for OpenHands, an open-source AI software engineer. This project wraps that interface in a thin Capacitor shell so it installs and runs like any other Android app. You still point it at your own OpenHands backend. The app is the client, not the server.

A real app, not a shortcut

Native Android package with its own launcher icon, splash screen and back-button handling. Not a browser bookmark.

Universal build

One APK for every device. No native libraries and no ABI split, so it installs on arm64, armv7 and x86.

Minimal permissions

INTERNET and nothing else. No storage, no contacts, no location, no advertising ID.

Reproducible

Every release is built from source in public by GitHub Actions. The workflow is committed, so you can audit or rerun it.

Runs on old hardware

Targets Android 6.0 (API 23) and up, so it works on phones that no longer receive updates.

Honest about its limits

A community packaging, not an official OpenHands release. It needs a backend you control to be useful.

02 · Capabilities

Everything the web UI does, on a phone.

The app ships the actual Agent Canvas bundle, so the feature set tracks upstream: conversations, file diffs, terminal output and multi-step agent runs, rendered for touch.

01

Agent conversations

Start a task in plain language and watch the agent plan, run tools and report back step by step.

02

Live code diffs

See exactly which files changed and what was edited before anything is merged.

03

Terminal output

Command output streams into the conversation, so failures are visible while they happen.

04

Session history

Reopen earlier conversations and pick up a task where you left it.

05

Your own backend

Point it at a self-hosted OpenHands server. Nothing is routed through a third party.

06

Launches offline

The shell starts without a network. Only agent calls need connectivity.

03 · Install

Four steps, about a minute.

Android will warn you about installing outside the Play Store. That warning is expected for any sideloaded app.

STEP 01

Download the APK

Tap the download button. The file is about 6.0 MB. If your browser asks, choose “Download anyway”.

STEP 02

Allow installs from this source

Open the file from your notifications or the Downloads folder. If Android blocks it, tap Settings and enable “Allow from this source” for your browser or file manager.

STEP 03

Install and open

Tap Install. If Play Protect shows a scan prompt, tap “Install anyway”. The app appears as OpenHands.

STEP 04

Connect your backend

On first launch, enter the address of your OpenHands server. You can change it later in settings.

Upgrading from a build older than v1.27.2? That version was signed with a different key. Android will refuse to install over the top, so uninstall the old app first. Your app settings go with it, so note your agent server URL before you upgrade.

05 · FAQ

Questions people actually ask.

Is this an official OpenHands release?
No. This is an independent, community packaging of the OpenHands Agent Canvas web interface. All credit for the application itself belongs to the OpenHands project and its contributors.
Do I need an OpenHands backend?
Yes, for the agent features. The app is the client. Point it at a self-hosted OpenHands server you control, and nothing is routed through a third party.
Does it work without the Play Store?
That is the whole point. You sideload the APK directly from GitHub Releases. Android shows a standard sideload warning, which is expected.
What permissions does it request?
Only INTERNET. No storage, no contacts, no location, and no advertising ID.
Which Android versions are supported?
Android 6.0 (API 23) and up. The APK is universal, so the same file installs on arm64, armv7 and x86 devices.
How do I get updates?
Download the latest APK again, or add the app to Obtainium and it will notify you when a new release is published.
Why does Android warn me during install?
Any app installed outside the Play Store triggers that warning. You can verify the build against the published hashes before installing.
