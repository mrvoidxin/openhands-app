Install

Four steps, about a minute.

Sideloading an APK is a normal Android flow. Android will ask you to allow it once.

01

Download the APK

Tap the download button. The file is about 6.2 MB and works on every architecture.

02

Allow installs from this source

Open the file and Android will offer to allow your browser to install apps. Accept it.

03

Install and open

Finish the install, then open the app. It will ask for your backend address.

04

Connect your backend

Enter your OpenHands server URL. You can change it later in settings.

Coming from a build older than v1.27.2? The signing key changed, so Android will refuse the update. Uninstall the old app first, then install this one. Note your server URL before you do — you will need to enter it again.
