01
Overview

What this actually is.

OpenHands Agent Canvas is the web interface for OpenHands, an open-source AI software engineer. This project wraps that interface in a thin Capacitor shell so it installs and runs like any other Android app. You still point it at your own OpenHands backend — the app is the client, not the server.

01

A real app, not a shortcut

Native Android package with its own launcher icon, splash screen and back-button handling — not a browser bookmark.

02

Universal build

One APK for every device. No native libraries and no ABI split, so it installs on arm64, armv7 and x86 alike.

03

Minimal permissions

INTERNET and nothing else. No storage, no contacts, no location, no advertising ID.

04

Reproducible

Every release is built from source in public by GitHub Actions. The workflow is committed, so you can audit or rerun it.

05

Runs on old hardware

Targets Android 6.0 (API 23) and up, so it works on phones that no longer receive updates.

06

Honest about its limits

It is a community packaging, not an official OpenHands release, and it needs a backend you control to be useful.

02
Capabilities

Everything the web UI does, on a phone.

Because it ships the actual Agent Canvas bundle, the feature set tracks upstream: conversation history, file diffs, terminal output and multi-step agent runs, all rendered for a touch screen.

→

Agent conversations

Start a task in plain language and watch the agent plan, run tools and report back step by step.

→

Live code diffs

See exactly which files changed and what was edited before anything is merged.

→

Terminal output

Command output streams into the conversation, so failures are visible while they happen.

→

Session history

Reopen earlier conversations and pick up a task where you left it.

→

Your own backend

Point it at a self-hosted OpenHands server. Nothing is routed through a third party.

→

Launches offline

The shell starts without a network; only the agent calls themselves need connectivity.

03
Install

Four steps, about a minute.

Android will warn you about installing outside the Play Store. That warning is expected for any sideloaded app.

Upgrading from a build older than v1.27.2? That version was signed with a different key. Android refuses to install this over the top, so uninstall the old app first. Your app settings go with it — note your agent server URL before you upgrade.
STEP 01

Download the APK

Tap the download button. The file is about 6.0 MB. If your browser asks, choose Download anyway.

STEP 02

Allow installs from this source

Open the file from your notifications or the Downloads folder. When Android blocks it, tap Settings and enable Allow from this source for your browser or file manager.

STEP 03

Install and open

Tap Install. Play Protect may show a scan prompt — tap Install anyway. The app appears as OpenHands.

STEP 04

Connect your backend

On first launch, enter the address of your OpenHands server. You can change it later in settings.
